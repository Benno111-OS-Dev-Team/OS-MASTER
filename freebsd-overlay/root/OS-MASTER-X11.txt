OS-MASTER preinstalls X11 into the installer and the target system.
The live media launches a graphical installer session, and the installed
system restores the May 2026 desktop layout with the original wallpaper set,
dock icons, dark top bar, and a graphical login screen.

The installed system should present the desktop login on `ttyv8`.
From a shell, the fallback launch command is:

  startx
